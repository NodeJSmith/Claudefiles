Usage: ado-api pr COMMAND [OPTIONS]

Pull request operations

╭─ Commands ───────────────────────────────────────────────────────────────────────────────────────╮
│ create            Create a pull request.                                                         │
│ list              List pull requests.                                                            │
│ reply             Reply to a PR thread.                                                          │
│ resolve           Resolve one or more threads on a pull request.                                 │
│ resolve-pattern   Resolve threads whose content matches a regex pattern (dry-run by default).    │
│ show              Show PR details (auto-detects from branch if omitted).                         │
│ thread-add        Add a new comment thread on a pull request.                                    │
│ threads           List PR threads (auto-detects PR from branch if omitted).                      │
│ update            Update a pull request.                                                         │
│ work-item-add     Link work items to a pull request.                                             │
│ work-item-create  Create a work item and link it to a pull request.                              │
│ work-item-list    List work items linked to a pull request.                                      │
│ work-item-remove  Unlink work items from a pull request.                                         │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Parameters ─────────────────────────────────────────────────────────────────────────────────────╮
│ --json     Output as JSON. No effect on setup, pipeline create, or pipeline build-validate.      │
│            [default: False]                                                                      │
│ --project                                                                                        │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
